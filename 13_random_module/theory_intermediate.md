# Тема 13: Модуль random

В Scratch случайность задавалась блоком "выбрать случайное число от ...
до ...". В Python то же самое делает модуль `random` из стандартной
библиотеки.

```python
import random

random.randint(1, 6)      # случайное целое число от 1 до 6 включительно
random.choice(["a", "b", "c"])   # случайный элемент из списка/кортежа
```

`random.randint(a, b)` включает обе границы — это отличается от многих
других языков, где верхняя граница не включается, так что при переносе
логики из других языков будь внимателен.

Есть и другие полезные функции модуля (пригодятся позже):

```python
random.random()          # случайное дробное число от 0.0 до 1.0
random.shuffle(список)   # перемешивает список "на месте"
```

## Воспроизводимость: random.seed()

Генератор случайных чисел в Python на самом деле **псевдослучайный** —
он вычисляет числа по формуле, отталкиваясь от "стартовой точки"
(seed). Если задать `seed` вручную, последовательность "случайных"
чисел станет одинаковой при каждом запуске — это удобно для тестов и
отладки.

```python
import random

random.seed(42)
print(random.randint(1, 100))  # всегда одно и то же число при seed=42
print(random.randint(1, 100))  # следующее число тоже всегда одинаковое
```

В учебных задачах этой темы мы фиксируем `seed`, чтобы результат
программы был предсказуемым и его можно было проверить автоматически.

## Запомни

- `import random` подключает модуль случайных чисел из стандартной библиотеки.
- `random.randint(a, b)` — целое число от `a` до `b`, обе границы включены.
- `random.choice(seq)` — случайный элемент последовательности.
- `random.seed(n)` фиксирует стартовую точку генератора — результат
  становится повторяемым и проверяемым.
