# Тема 13: Модуль random

## Компьютер тоже умеет "кидать кубик"

Ты наверняка играл в игры, где что-то происходит случайно: выпадает
кубик, из колоды приходит случайная карта, компьютер выбирает случайного
противника. В Python за такие "случайности" отвечает специальный
инструмент — **модуль `random`**.

Модуль — это как отдельный набор инструментов, который нужно сначала
"позвать" в свою программу командой `import`:

```python
import random
```

После этого можно пользоваться его командами.

## random.randint() — случайное число

`random.randint(a, b)` выбирает случайное **целое** число от `a` до `b`
включительно (то есть `b` тоже может выпасть).

```python
import random

число = random.randint(1, 6)   # как бросок игрального кубика
print("Выпало число:", число)
```

Каждый раз, когда запускаешь программу заново, число может быть другим —
это и есть случайность.

## random.choice() — случайный выбор из списка

`random.choice(список)` выбирает один случайный элемент из списка.

```python
import random

варианты = ["камень", "ножницы", "бумага"]
выбор = random.choice(варианты)
print("Компьютер выбрал:", выбор)
```

## Как проверять программу со случайностями

Если число всё время случайное, как проверить, что программа работает
правильно? Для этого используют `random.seed(число)` — команду, которая
говорит: "начни генерировать случайные числа с этой же самой точки".
Тогда результат всегда будет одинаковым, и программу можно проверить.

```python
import random

random.seed(42)             # фиксируем "точку отсчёта"
print(random.randint(1, 6))  # результат всегда будет один и тот же
```

В своих учебных задачах мы будем использовать `random.seed(...)`, чтобы
результат программы можно было предсказать и проверить.

## Запомни

- `import random` — подключает модуль случайных чисел.
- `random.randint(a, b)` — случайное целое число от `a` до `b` включительно.
- `random.choice(список)` — случайный элемент из списка.
- `random.seed(число)` — делает "случайность" повторяемой (для проверки).
