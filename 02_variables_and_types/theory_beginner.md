# Тема 2: Переменные и типы данных

## Переменная — это подписанная коробка

Представь, что у тебя есть коробка. Ты кладёшь в неё игрушку и
приклеиваешь на коробку стикер с названием, например "любимая машинка".
Теперь, если ты скажешь "принеси мне любимую машинку", все поймут, о
какой коробке речь.

В программировании такая "подписанная коробка" называется
**переменная**. Мы кладём в неё какое-то значение и даём ему имя:

```python
name = "Миша"
age = 12
```

Здесь `name` и `age` — это имена переменных (стикеры на коробках), а
`"Миша"` и `12` — значения, которые мы туда положили. Знак `=` здесь не
"равно", как в математике, а команда "положи в коробку":
"положи в коробку `name` значение `"Миша"`".

Чтобы посмотреть, что лежит в коробке, используем уже знакомый `print()`:

```python
name = "Миша"
age = 12
print(name)
print(age)
```

На экране появится:

```
Миша
12
```

## Разные типы значений

В коробки можно класть разные вещи, и Python различает несколько
основных **типов данных**:

- **`str`** (от слова *string* — строка) — текст в кавычках: `"Миша"`,
  `"Привет!"`.
- **`int`** (от слова *integer* — целое число) — целые числа без
  точки: `12`, `-5`, `1000`.
- **`float`** (от слова *floating point* — плавающая точка) — дробные
  числа с точкой: `3.14`, `160.5`.
- **`bool`** (от слова *boolean*, в честь математика Джорджа Буля) —
  всего два значения: `True` (правда) или `False` (ложь).

```python
name = "Миша"        # str — текст
age = 12             # int — целое число
height = 148.5        # float — дробное число
likes_python = True   # bool — да/нет
```

Python сам угадывает тип по тому, как выглядит значение: если в кавычках
— значит `str`, если число без точки — `int`, с точкой — `float`, а
`True`/`False` — это `bool`.

## Как называть переменные

Имя переменной — как стикер на коробке, оно должно быть понятным. Есть
несколько правил:

- Имя может состоять из букв, цифр и знака `_` (нижнее подчёркивание),
  но не может начинаться с цифры.
- В именах нельзя использовать пробелы — вместо пробела пишут `_`,
  например `my_age`, а не `my age`.
- Лучше выбирать имена, которые понятны без пояснений: `age` лучше, чем
  `x`.

```python
my_age = 12          # хорошо
favorite_game = "Minecraft"  # хорошо
2cool = "нет"         # так нельзя — имя не может начинаться с цифры!
```

## Запомни

- Переменная — это "подписанная коробка" для значения: `имя = значение`.
- `str` — текст в кавычках, `int` — целое число, `float` — дробное число,
  `bool` — `True` или `False`.
- Имя переменной не может начинаться с цифры и не может содержать пробелы.
- Значение переменной можно посмотреть через `print(имя_переменной)`.
