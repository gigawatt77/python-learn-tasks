# Тема 2: Переменные и типы данных

Переменная — это имя, привязанное к значению в памяти компьютера.
Присваивание делается оператором `=`:

```python
name = "Аня"
age = 12
height = 148.5
likes_python = True

print(name, age, height, likes_python)
```

Python — язык с **динамической типизацией**: тип переменной не нужно
указывать заранее, он определяется автоматически по значению и может
поменяться, если положить в переменную что-то другое:

```python
value = 10        # сейчас int
value = "десять"   # теперь str, и это нормально для Python
```

Основные встроенные типы:

| Тип     | Пример          | Что это                      |
|---------|-----------------|-------------------------------|
| `str`   | `"текст"`       | строка (текст)                |
| `int`   | `42`            | целое число                   |
| `float` | `3.14`          | число с плавающей точкой      |
| `bool`  | `True`/`False`  | логическое значение           |

Узнать тип значения можно функцией `type()`:

```python
age = 12
print(type(age))      # <class 'int'>
```

Правила именования переменных: буквы, цифры и `_`, не может начинаться
с цифры, регистр важен (`age` и `Age` — разные переменные), зарезервированные
слова языка (`print`, `if`, `for` и т.д.) использовать как имена нельзя.
По договорённости имена переменных пишут в стиле `snake_case`:
`my_favorite_game`, а не `MyFavoriteGame`.

```python
score = 100
Score = 200     # это другая переменная!
print(score, Score)
```

## Запомни

- `=` — присваивание, а не математическое равенство.
- Основные типы: `str`, `int`, `float`, `bool`.
- Тип переменной определяется автоматически и может измениться.
- `type(x)` показывает текущий тип значения переменной `x`.
- Имена переменных: `snake_case`, без пробелов, не начинаются с цифры.
