# Тема 3: input() и преобразование типов

## Как спросить у пользователя что-то

До сих пор мы сами придумывали значения для переменных прямо в коде.
Но что, если мы хотим, чтобы программа спросила что-то у человека,
который её запустил? Для этого есть функция **`input()`**.

```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```

Когда программа доходит до строки с `input()`, она печатает вопрос
`"Как тебя зовут? "` и ждёт, пока человек напечатает ответ и нажмёт
Enter. То, что человек напечатал, сохраняется в переменную `name`.

Представь, что `input()` — это как открытая дверь: программа
останавливается и ждёт, пока кто-то что-то не скажет, а потом кладёт
услышанное в коробку-переменную.

## Важно: input() всегда возвращает текст

Даже если человек введёт число, `input()` вернёт его как **строку**
(`str`), а не как число! Это частая ловушка для новичков:

```python
age = input("Сколько тебе лет? ")
print(type(age))   # <class 'str'> — это строка, а не число!
```

Если попробовать посчитать что-то с этой "строкой-числом" как с
настоящим числом, Python выдаст ошибку. Чтобы это исправить, нужно
**преобразовать** текст в число.

## Преобразование типов

Для превращения одного типа в другой есть специальные функции-команды:

- **`int(x)`** — превращает `x` в целое число.
- **`float(x)`** — превращает `x` в дробное число.
- **`str(x)`** — превращает `x` в текст.

```python
age_text = input("Сколько тебе лет? ")   # это строка, например "12"
age_number = int(age_text)                # а теперь это число 12

next_year_age = age_number + 1
print("В следующем году тебе будет", next_year_age)
```

Если попытаться превратить в число что-то, что числом не является
(например, слово "привет"), Python покажет ошибку `ValueError`. Это
нормально — просто нужно вводить именно число, когда программа его
просит.

## Запомни

- `input("вопрос")` печатает вопрос и ждёт ответ пользователя.
- То, что вернул `input()`, — всегда строка (`str`), даже если это
  выглядит как число.
- `int(x)` превращает `x` в целое число, `float(x)` — в дробное число,
  `str(x)` — в текст.
- Если ввести не число, а попытаться превратить это в число, Python
  выдаст ошибку `ValueError`.
