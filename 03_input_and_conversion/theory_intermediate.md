# Тема 3: input() и преобразование типов

`input([prompt])` приостанавливает выполнение программы, печатает
необязательное приглашение `prompt` и читает одну строку с клавиатуры
(до нажатия Enter). Результат всегда имеет тип `str`:

```python
name = input("Как тебя зовут? ")
print(type(name))   # <class 'str'>
```

Так как `input()` всегда возвращает строку, для арифметики со введёнными
данными нужно явное приведение типа (**type casting**):

```python
age = int(input("Сколько тебе лет? "))
height = float(input("Какой у тебя рост в см? "))

print(age + 1)
print(height / 2)
```

Основные функции преобразования:

| Функция    | Преобразует в... | Пример              |
|------------|-------------------|-----------------------|
| `int(x)`   | целое число        | `int("12")` → `12`   |
| `float(x)` | дробное число      | `float("3.5")` → `3.5` |
| `str(x)`   | строку             | `str(12)` → `"12"`   |

Если строку нельзя превратить в число (например, `int("привет")`),
Python вызовет исключение `ValueError` и программа остановится с
ошибкой. Позже вы научитесь такие ошибки обрабатывать (`try/except`),
а пока просто важно вводить именно то, что просит программа.

Совет: у `input()` можно сразу же преобразовать результат, не создавая
промежуточную строковую переменную — это частый и удобный приём:

```python
number = int(input("Введи число: "))
```

## Запомни

- `input()` всегда возвращает `str`, даже для чисел.
- `int(x)`, `float(x)`, `str(x)` — преобразование типов.
- Преобразование обычно делают сразу же: `int(input("..."))`.
- Некорректный ввод при преобразовании вызывает ошибку `ValueError`.
