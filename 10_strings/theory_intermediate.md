# Тема 10: Строки

Строка (`str`) — неизменяемая последовательность символов. Индексация и
срезы работают так же, как у списков: `s[i]`, `s[a:b:c]`,
отрицательные индексы считают с конца.

```python
s = "Программирование"
print(s[0], s[-1])   # П е
print(s[3:8])         # рамми
print(s[::-1])        # строка задом наперёд
```

## Методы строк

Методы возвращают новую строку — исходная не меняется, потому что
строки immutable:

```python
s = "  Привет, Мир!  "

print(s.strip())              # убрать пробелы по краям
print(s.upper())              # ПРИВЕТ, МИР!
print(s.lower())              # привет, мир!
print(s.replace("Мир", "Python"))
print(s.strip().split(", "))  # ['Привет', 'Мир!']
print(s.find("Мир"))          # индекс подстроки (или -1, если не найдена)
print("мир" in s.lower())     # проверка вхождения подстроки -> True/False
```

`"разделитель".join(список)` — обратная операция к `split()`: собирает
список строк обратно в одну строку.

```python
words = ["Python", "это", "круто"]
print(" ".join(words))   # Python это круто
```

## f-строки

f-строки (formatted string literals) позволяют вставлять выражения прямо
в текст через `{}`, включая вычисления и форматирование чисел:

```python
name = "Аня"
score = 91.567
print(f"{name} набрала {score:.1f} баллов")   # Аня набрала 91.6 баллов
print(f"Квадрат числа 5 = {5 ** 2}")           # можно писать выражения внутри {}
```

## Запомни

- Строки неизменяемы: методы возвращают новую строку, не меняя старую.
- `s[a:b:c]` — срез строки: начало, конец, шаг.
- `upper/lower/strip/replace/split/find` — основные методы обработки текста.
- `"".join(список)` — собрать список строк в одну строку.
- `f"{переменная}"` и `f"{значение:.1f}"` — f-строки со вставкой и
  форматированием значений.
