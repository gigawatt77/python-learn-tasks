# Тема 10: Строки

## Строка — это тоже последовательность

Строка (`str`) — это текст в кавычках: `"Привет"`. Но для Python строка —
это ещё и **последовательность символов**, как поезд из вагончиков, где
каждый вагончик — одна буква. И, точно как в списке, у каждого символа
есть свой номер — индекс, начиная с нуля!

```python
word = "Питон"
print(word[0])   # П
print(word[1])   # и
print(word[-1])  # н (последний символ)
```

## Срезы строк

Срезы работают так же, как у списков — можно достать кусок строки:

```python
word = "Программирование"
print(word[0:5])   # Прогр
print(word[:4])    # Прог
print(word[-3:])   # ние
```

## len() — длина строки

Функция `len()` считает, сколько символов в строке (включая пробелы!):

```python
name = "Миша"
print(len(name))   # 3
```

## Полезные методы строк

У строк есть встроенные "команды" (методы), которые помогают их
обрабатывать:

```python
text = "Привет, Мир!"

print(text.upper())         # ПРИВЕТ, МИР!  — всё заглавными
print(text.lower())         # привет, мир!  — всё строчными
print(text.replace("Мир", "Python"))  # Привет, Python!  — замена части текста
print(text.split(", "))     # ['Привет', 'Мир!']  — разбить на список по разделителю
print(text.find("Мир"))     # 8  — с какого индекса начинается "Мир"
```

Важно: методы **не меняют** исходную строку — они возвращают **новую**
строку. Строки в Python вообще нельзя изменить "на месте" (это называется
неизменяемость).

## f-строки — удобная вставка значений в текст

Часто нужно вставить значение переменной прямо в текст. Для этого перед
кавычками ставят букву `f` и внутри строки пишут переменную в фигурных
скобках `{}`:

```python
name = "Миша"
age = 12
print(f"Меня зовут {name}, мне {age} лет.")
```

Результат:

```
Меня зовут Миша, мне 12 лет.
```

Это гораздо удобнее, чем склеивать строки через `+`.

## Запомни

- Строка — последовательность символов, индексы с нуля: `text[0]`.
- Срез: `text[a:b]` — часть строки с индекса `a` до `b`.
- `len(text)` — длина строки.
- `text.upper()`, `text.lower()` — заглавные / строчные буквы.
- `text.split(разделитель)` — разбить строку на список.
- `text.replace(старое, новое)` — заменить часть текста.
- `text.find(подстрока)` — найти индекс подстроки.
- `f"текст {переменная}"` — f-строка, вставляет значение переменной в текст.
