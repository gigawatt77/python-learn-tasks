# Тема 4: Арифметика и операторы

## Python умеет считать

Python — отличный калькулятор. Можно прямо в коде написать
математическое выражение, и он его посчитает:

```python
print(2 + 3)
print(10 - 4)
print(6 * 7)
```

На экране появится:

```
5
6
42
```

Значки `+`, `-`, `*` называются **операторами** — это специальные
символы, которые говорят Python, что сделать с числами вокруг них.

## Основные арифметические операторы

- `+` — сложение: `5 + 3` → `8`
- `-` — вычитание: `5 - 3` → `2`
- `*` — умножение: `5 * 3` → `15`
- `/` — деление: `5 / 2` → `2.5` (всегда получается дробное число!)
- `//` — **целочисленное деление**: `5 // 2` → `2` (делим и отбрасываем
  остаток, оставляем только целую часть)
- `%` — **остаток от деления**: `5 % 2` → `1` (сколько осталось "лишнего"
  после целочисленного деления)
- `**` — возведение в степень: `2 ** 3` → `8` (это `2 * 2 * 2`)

```python
apples = 17
friends = 5

each = apples // friends       # сколько яблок достанется каждому целиком
leftover = apples % friends    # сколько яблок останется лишних

print(each)       # 3
print(leftover)   # 2
```

Представь, что `//` и `%` — это когда ты делишь яблоки между друзьями
поровну: `//` говорит, сколько целых яблок получит каждый, а `%` —
сколько яблок останется, которые не поделились поровну.

## Что считается первым — приоритет операций

Python, как и в математике, сначала выполняет умножение, деление,
`//` и `%`, а уже потом сложение и вычитание. А степень `**` вообще
самая "главная":

```python
result = 2 + 3 * 4
print(result)   # 14, а не 20! Сначала 3 * 4 = 12, потом + 2
```

Если хочешь, чтобы что-то посчиталось раньше, используй круглые скобки
`()` — точно как в математике:

```python
result = (2 + 3) * 4
print(result)   # 20, потому что сложение в скобках выполняется первым
```

## Запомни

- `+ - * /` — обычная арифметика, `/` всегда даёт дробное число.
- `//` — целая часть от деления, `%` — остаток от деления.
- `**` — возведение в степень.
- Порядок действий: сначала `**`, потом `* / // %`, потом `+ -`.
- Скобки `()` меняют порядок — то, что внутри них, считается первым.
