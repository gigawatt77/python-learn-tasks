# Тема 4: Арифметика и операторы

Python поддерживает стандартный набор арифметических операторов:

| Оператор | Действие                  | Пример      | Результат |
|----------|----------------------------|-------------|-----------|
| `+`      | сложение                   | `7 + 2`     | `9`       |
| `-`      | вычитание                  | `7 - 2`     | `5`       |
| `*`      | умножение                  | `7 * 2`     | `14`      |
| `/`      | деление (всегда `float`)   | `7 / 2`     | `3.5`     |
| `//`     | целочисленное деление      | `7 // 2`    | `3`       |
| `%`      | остаток от деления (mod)   | `7 % 2`     | `1`       |
| `**`     | возведение в степень       | `2 ** 3`    | `8`       |

Обрати внимание: `/` всегда возвращает `float`, даже если числа делятся
без остатка (`10 / 2` → `5.0`, а не `5`). А `//` и `%` очень удобны для
задач вроде "разложить N предметов по K коробкам поровну и посчитать
остаток":

```python
total = 23
box_size = 5

full_boxes = total // box_size   # 4 полные коробки
remainder = total % box_size     # 3 предмета останутся
```

**Приоритет операций** (от высшего к низшему):

1. `()` — скобки считаются первыми
2. `**` — возведение в степень
3. `* / // %` — умножение и деление (равный приоритет, считаются слева
   направо)
4. `+ -` — сложение и вычитание (равный приоритет, слева направо)

```python
print(2 + 3 ** 2)        # 11  (сначала 3**2=9, потом 2+9)
print((2 + 3) ** 2)      # 25  (скобки меняют порядок)
print(10 - 4 / 2)        # 8.0 (сначала 4/2=2.0, потом 10-2.0)
print(2 * 3 + 4 * 5)     # 26  (умножения выполняются первыми: 6 + 20)
```

Если выражение получается сложным для чтения — не стесняйся добавлять
скобки, даже если по приоритету они не обязательны. Это делает код
понятнее.

## Запомни

- `/` всегда возвращает `float`, `//` — целую часть, `%` — остаток.
- `**` — возведение в степень, самый "сильный" оператор.
- Порядок: `()` → `**` → `* / // %` → `+ -`.
- При одинаковом приоритете операции выполняются слева направо.
