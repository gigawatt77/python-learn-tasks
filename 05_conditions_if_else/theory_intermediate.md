# Тема 5: условия if / elif / else

В блочном программировании (Scratch) ты уже видел блок "если... то...
иначе...". В Python это записывается текстом через `if` / `elif` /
`else`, а вместо "защёлкивания" блоков используются отступы (обычно
4 пробела).

```python
temperatura = 15

if temperatura > 25:
    print("Жарко")
elif temperatura > 15:
    print("Тепло")
elif temperatura > 0:
    print("Прохладно")
else:
    print("Холодно")
```

Python проверяет условия по порядку сверху вниз и выполняет **только
первую** ветку, условие которой оказалось `True`. Остальные `elif`/`else`
пропускаются, даже если их условие тоже было бы верным.

## Операторы сравнения и тип bool

Результат сравнения — значение типа `bool`: `True` или `False`.

```python
print(7 > 3)        # True
print(7 == 3)        # False
print(type(7 > 3))   # <class 'bool'>
```

Операторы: `==`, `!=`, `>`, `<`, `>=`, `<=`. Частая ошибка новичков —
перепутать `=` (присваивание) и `==` (сравнение).

## Вложенные условия

`if` можно вкладывать друг в друга — тогда внутренний блок получает
ещё один уровень отступа:

```python
vozrast = 14
bilet_est = True

if vozrast >= 12:
    if bilet_est:
        print("Проходи в зал")
    else:
        print("Сначала купи билет")
else:
    print("Фильм для тех, кто постарше")
```

## Короткая запись (тернарный оператор)

Для простых случаев есть однострочная форма `if`/`else`:

```python
vozrast = 10
status = "взрослый" if vozrast >= 18 else "ребёнок"
print(status)   # ребёнок
```

## Запомни

- `if`/`elif`/`else` выбирают одну ветку выполнения из нескольких.
- Отступы (4 пробела) — это синтаксис Python, а не оформление.
- Сравнение `==` и присваивание `=` — разные операторы, не путай их.
- Условия можно вкладывать друг в друга (вложенный `if`).
- `значение_если_true if условие else значение_если_false` — короткая
  запись условия в одну строку.
