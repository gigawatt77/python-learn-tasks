# Тема 5: условия if / elif / else

## Компьютер тоже умеет выбирать

Представь: ты стоишь перед дверью и думаешь — "если на улице дождь, возьму
зонт, а если нет — не возьму". Ты принимаешь решение в зависимости от
условия. Программы тоже умеют так делать! Для этого в Python есть команда
**`if`** (по-английски значит "если").

```python
pogoda = "дождь"

if pogoda == "дождь":
    print("Возьми зонт!")
```

Разберём по кусочкам:
- `if` — "если". После него пишем условие.
- `pogoda == "дождь"` — само условие. Два знака равенства `==` означают
  "равно ли?" (проверка), а не "положить в коробку" (это делает один
  знак `=`).
- `:` — двоеточие обязательно ставится после условия.
- Строка `print("Возьми зонт!")` написана с отступом (несколько
  пробелов слева). Такой блок с отступом выполнится, только если
  условие оказалось верным (True).

## Что делать, если условие не подошло?

Для этого есть **`else`** — "иначе":

```python
vozrast = 10

if vozrast >= 12:
    print("Тебе можно на этот фильм")
else:
    print("Тебе ещё рано на этот фильм")
```

Если условие `vozrast >= 12` верно — выполнится первый блок. Если нет —
выполнится блок после `else`.

## А если вариантов больше двух?

Тогда на помощь приходит **`elif`** (сокращение от "else if" — "иначе
если"). Можно проверять условия по очереди, одно за другим:

```python
ocenka = 4

if ocenka == 5:
    print("Отлично!")
elif ocenka == 4:
    print("Хорошо!")
elif ocenka == 3:
    print("Удовлетворительно")
else:
    print("Нужно подучить")
```

Python проверяет условия сверху вниз и выполняет только первый блок,
который оказался верным. Остальные пропускает.

## Операторы сравнения

Чтобы задавать условия, нужны специальные знаки сравнения:

- `==` — равно
- `!=` — не равно
- `>` — больше
- `<` — меньше
- `>=` — больше или равно
- `<=` — меньше или равно

Результат сравнения — это всегда `True` (правда) или `False` (ложь).

```python
print(5 > 3)      # True
print(5 == 3)     # False
```

## Отступы — это важно!

В Python отступы (пробелы в начале строки) — не просто красота, а часть
языка! Всё, что относится к блоку `if`, должно иметь одинаковый отступ
(обычно 4 пробела). Если забыть отступ — Python выдаст ошибку.

## Запомни

- `if условие:` — выполняет блок кода, если условие верно (True).
- `else:` — выполняется, если условие оказалось неверным (False).
- `elif условие:` — дополнительная проверка, если предыдущие условия
  не подошли.
- Сравнение: `==`, `!=`, `>`, `<`, `>=`, `<=`.
- После `if`, `elif`, `else` обязательно ставится `:`.
- Код внутри блока пишется с отступом (обычно 4 пробела).
