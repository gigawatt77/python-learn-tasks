# Тема 7: цикл while, break и continue

## Когда нужно повторять действие снова и снова

Представь: мама просит тебя мыть посуду, "пока вся посуда не станет
чистой". Ты не моешь одну тарелку и останавливаешься — ты повторяешь
действие, пока условие ("посуда грязная") остаётся верным. В Python
для таких повторений есть цикл **`while`** ("пока").

```python
schet = 1

while schet <= 3:
    print("Раз!")
    schet = schet + 1
```

Этот код напечатает "Раз!" три раза. Разберём:
- `while schet <= 3:` — "пока schet меньше или равно 3, повторяй".
- Внутри цикла (с отступом) — код, который повторяется.
- `schet = schet + 1` — очень важная строка! Она увеличивает счётчик,
  иначе условие никогда не станет False, и цикл будет крутиться вечно
  (это называется "бесконечный цикл" — его надо избегать).

## Как остановить цикл раньше времени

Иногда нужно выйти из цикла досрочно, не дожидаясь, пока условие само
станет False. Для этого есть команда **`break`** ("прервать"):

```python
schet = 1

while schet <= 10:
    if schet == 4:
        break               # как только schet станет 4 — выходим из цикла
    print(schet)
    schet = schet + 1
```

Этот код напечатает только `1 2 3`, а на числе 4 цикл прервётся.

## Как пропустить один шаг цикла

Команда **`continue`** ("продолжить") пропускает оставшуюся часть тела
цикла и сразу переходит к следующей проверке условия:

```python
schet = 0

while schet < 5:
    schet = schet + 1
    if schet == 3:
        continue            # пропускаем print для числа 3
    print(schet)
```

Этот код напечатает `1 2 4 5` — число 3 будет пропущено.

## Осторожно: бесконечный цикл!

Если забыть изменить переменную, от которой зависит условие, цикл
никогда не остановится. Программа "зависнет". Всегда проверяй, что
внутри цикла есть что-то, что рано или поздно сделает условие False.

## Запомни

- `while условие:` — повторяет блок кода, пока условие остаётся True.
- Обязательно меняй переменную внутри цикла, иначе получится
  бесконечный цикл.
- `break` — немедленно прерывает цикл целиком.
- `continue` — пропускает текущий шаг и переходит к следующей проверке
  условия.
