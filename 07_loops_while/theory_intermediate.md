# Тема 7: цикл while, break и continue

В Scratch есть блок "повторять, пока..." — это и есть аналог `while` в
Python. Цикл `while` выполняет тело, пока условие остаётся `True`, и
проверяет условие перед каждой итерацией (в том числе перед самой
первой — если условие сразу False, тело не выполнится ни разу).

```python
schet = 1

while schet <= 3:
    print("Итерация", schet)
    schet += 1              # schet += 1 то же самое, что schet = schet + 1
```

## break и continue

`break` полностью завершает ближайший цикл, а `continue` завершает
только текущую итерацию и переходит к следующей проверке условия.
Оба часто используются вместе с `if` внутри цикла:

```python
schet = 0

while True:                 # условие всегда True — "бесконечный" цикл
    schet += 1
    if schet % 2 == 0:
        continue             # пропускаем чётные числа
    if schet > 7:
        break                 # выходим, когда число больше 7
    print(schet)
```

Такой шаблон (`while True` + `break` внутри) удобен, когда условие
выхода сложно сформулировать заранее, до первой итерации.

## Счётчик и накопитель

Частый паттерн — считать сумму или количество элементов с помощью
переменной-накопителя:

```python
schet = 1
summa = 0

while schet <= 5:
    summa += schet
    schet += 1

print("Сумма от 1 до 5:", summa)   # 15
```

## Опасность бесконечного цикла

Если условие никогда не станет `False` (и нет `break`), программа
зависнет. При отладке всегда проверяй, что переменная в условии
действительно меняется внутри тела цикла.

## Запомни

- `while условие:` проверяет условие перед каждой итерацией.
- `break` — выход из цикла целиком; `continue` — переход к следующей
  проверке условия, минуя оставшийся код итерации.
- `while True` с `break` внутри — рабочий паттерн для сложных условий
  выхода.
- Не забывай менять переменную условия внутри цикла — иначе он
  бесконечный.
