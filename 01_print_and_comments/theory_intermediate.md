# Тема 1: print() и комментарии

Python выполняет код построчно, сверху вниз. Базовая функция вывода —
`print()`: она принимает один или несколько аргументов и печатает их
в консоль.

```python
print("Привет, мир!")
print("Python", "любит", "текст")          # аргументы через запятую -> вывод через пробел
print("Строка 1", "Строка 2", sep=" | ")   # sep меняет разделитель между аргументами
print("Без переноса строки", end=" ")
print("продолжение на той же строке")
```

Строки (тип `str`) задаются в одинарных `'...'` или двойных `"..."`
кавычках — разницы нет, главное быть последовательным. Если в тексте
нужны кавычки, удобно взять для строки другой тип кавычек:

```python
print("Она сказала: 'привет'")
print('Он ответил: "и тебе привет"')
```

Комментарии (`#`) — это часть строки, которую интерпретатор пропускает.
Используются для пояснений, временного отключения кода ("закомментировать
строку") и TODO-заметок:

```python
# print("этот код не выполнится")
print("а этот выполнится")  # пояснение к строке
```

## Запомни

- `print(*args, sep=' ', end='\n')` — базовые параметры вывода.
- `#` комментирует всё до конца строки; отдельного блочного комментария
  в Python нет (для многострочных пояснений иногда используют `"""..."""`).
- Синтаксические ошибки (незакрытая кавычка/скобка) выбрасывают
  `SyntaxError` ещё до запуска программы.
