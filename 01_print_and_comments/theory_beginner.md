# Тема 1: print() и комментарии

## С чего всё начинается

Компьютер сам по себе ничего не умеет — он делает ровно то, что ему
написали. Программа — это список команд для компьютера, записанный на
языке, который он понимает. Мы будем писать на языке **Python**.

Самая первая и самая важная команда — **`print()`**. Она говорит
компьютеру: "покажи это на экране".

```python
print("Привет, мир!")
```

Если запустить эту строку, на экране (в терминале) появится:

```
Привет, мир!
```

Разберём по кусочкам:
- `print` — имя команды. Как кнопка "напечатать".
- `(...)` — круглые скобки. Внутри них мы кладём то, что хотим напечатать.
- `"Привет, мир!"` — текст в кавычках. Кавычки — это как рамка вокруг
  текста, они говорят Python: "это именно текст, а не команда".

Можно напечатать несколько строк подряд — они появятся одна под другой:

```python
print("Привет!")
print("Меня зовут Python.")
print("Приятно познакомиться!")
```

## Комментарии

Иногда хочется оставить себе (или другу) заметку прямо в коде — но так,
чтобы компьютер её не выполнял. Для этого используют **комментарии**.
Всё, что стоит после символа `#` на строке, Python просто игнорирует.

```python
# Это комментарий, компьютер его не читает
print("А это уже настоящая команда")  # так тоже можно писать комментарий
```

Комментарии — это как стикеры-напоминалки на полях тетради. Они не
влияют на решение задачи, но помогают тебе (и другим людям) понять, что
происходит в коде.

## Ошибки — это нормально

Если ты забудешь закрыть кавычку или скобку, Python покажет тебе
красную ошибку (`SyntaxError`). Не пугайся! Просто прочитай, что
написано, и попробуй поправить. Даже опытные программисты ошибаются
каждый день.

## Запомни

- `print("текст")` — выводит текст на экран.
- Текст всегда пишется в кавычках: `"..."` или `'...'`.
- `#` — начало комментария, всё после него компьютер не выполняет.
- Каждая новая команда `print()` печатает свой текст с новой строки.
