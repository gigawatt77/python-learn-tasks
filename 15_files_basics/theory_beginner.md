# Тема 15: Работа с файлами

## Файл — это как тетрадка на диске

Всё, что печатает `print()`, исчезает, когда программа заканчивает
работу. А если мы хотим сохранить текст навсегда, чтобы он остался
на компьютере даже после закрытия программы? Для этого используют
**файлы** — как настоящую тетрадку, в которую можно что-то записать, а
потом снова открыть и прочитать.

## Открываем файл — open()

Команда `open()` открывает файл. Ей нужно сказать имя файла и режим
работы:

- `"w"` — write, писать (если файл уже был — старое содержимое сотрётся)
- `"r"` — read, читать
- `"a"` — append, дописать в конец, не стирая старое

```python
файл = open("заметка.txt", "w")   # открываем файл для записи
файл.write("Привет из файла!")    # записываем текст
файл.close()                      # обязательно закрываем файл!
```

Закрывать файл важно: пока файл не закрыт, Python может не успеть
до конца сохранить в него всё, что мы написали.

## Удобный способ — with open()

Есть более безопасный способ, который сам закрывает файл, даже если
в коде случится ошибка:

```python
with open("заметка.txt", "w") as файл:
    файл.write("Привет из файла!")
# здесь файл уже автоматически закрыт
```

## Читаем файл

```python
with open("заметка.txt", "r") as файл:
    содержимое = файл.read()   # читаем весь текст файла в одну строку
    print(содержимое)
```

## Запомни

- `open("имя.txt", "w")` — открыть файл для записи (старое содержимое
  стирается).
- `open("имя.txt", "r")` — открыть файл для чтения.
- `файл.write("текст")` — записать текст в файл.
- `файл.read()` — прочитать весь текст из файла.
- Лучше использовать `with open(...) as файл:` — тогда файл закроется
  сам.
