# Тема 15: Работа с файлами

В Scratch нет прямого аналога файлов на диске (кроме сохранения самого
проекта). В Python текстовые файлы читаются и пишутся через встроенную
функцию `open()`.

```python
файл = open("data.txt", "w", encoding="utf-8")
файл.write("строка текста")
файл.close()
```

Основные режимы открытия:

| Режим | Что делает |
|-------|-----------|
| `"r"` | чтение (файл должен существовать) |
| `"w"` | запись, старое содержимое стирается |
| `"a"` | дозапись в конец файла |

## Менеджер контекста with

Ручной `close()` легко забыть, особенно если между `open()` и `close()`
происходит ошибка — тогда файл может остаться незакрытым. Более
надёжный способ — конструкция `with`, которая гарантированно закрывает
файл при выходе из блока, даже при исключении:

```python
with open("data.txt", "w", encoding="utf-8") as файл:
    файл.write("привет")
# файл закрыт автоматически на этой строке
```

## Чтение файла

```python
with open("data.txt", "r", encoding="utf-8") as файл:
    текст = файл.read()       # весь файл одной строкой
    print(текст)
```

Есть и другие способы чтения: `readline()` (одна строка), `readlines()`
(список строк) — они пригодятся позже при работе с большими файлами.

## Пути к файлам

Если программа запускается из разных папок, относительный путь
`"data.txt"` может указывать на разные места. Чтобы файл всегда
находился рядом со скриптом, используют `__file__` и модуль `os`:

```python
import os

путь = os.path.join(os.path.dirname(__file__), "data.txt")
with open(путь, "w", encoding="utf-8") as файл:
    файл.write("надёжный путь к файлу")
```

## Запомни

- `open(имя, режим, encoding="utf-8")` — открыть файл.
- `"r"` — читать, `"w"` — писать (стирая старое), `"a"` — дописывать.
- `with open(...) as файл:` — надёжный способ, закрывает файл сам.
- `файл.write(текст)` и `файл.read()` — базовые операции с текстом.
- `os.path.join(os.path.dirname(__file__), "имя.txt")` — путь к файлу
  рядом со скриптом, независимо от текущей рабочей папки.
