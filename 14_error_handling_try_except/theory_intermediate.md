# Тема 14: Обработка ошибок (try/except)

В Scratch нет прямого аналога исключений — там просто ничего "не
происходит", если блок нельзя выполнить. В Python каждая ошибка во
время выполнения — это **исключение** (объект определённого типа),
и его можно перехватить конструкцией `try/except`, чтобы программа не
завершалась аварийно.

```python
try:
    рискованный_код()
except ТипОшибки:
    обработка_ошибки()
```

Если исключений в `try` не возникло — блок `except` пропускается
целиком. Если возникло исключение указанного типа — выполнение `try`
прерывается на этой строке, и управление сразу переходит в `except`.

## ValueError и ZeroDivisionError

Два самых частых исключения на старте:

```python
try:
    x = int("не число")
except ValueError:
    print("Нельзя превратить это в число")

try:
    y = 10 / 0
except ZeroDivisionError:
    print("Деление на ноль запрещено")
```

Можно перехватывать несколько типов ошибок в одном блоке — либо
отдельными `except`, либо через кортеж типов:

```python
try:
    a = int(текст)
    b = 100 / a
except ValueError:
    print("Это не число")
except ZeroDivisionError:
    print("Число не должно быть нулём")
```

Порядок важен: Python проверяет `except`-блоки по очереди и выполнит
только первый подходящий.

## Запомни

- Исключение — это объект-ошибка, который Python "выбрасывает" во
  время выполнения кода.
- `try/except` перехватывает исключение и не даёт программе упасть.
- `ValueError` — неправильное значение (например, `int("текст")`).
- `ZeroDivisionError` — деление на ноль.
- Можно указывать несколько блоков `except` для разных типов ошибок.
