# Тема 14: Обработка ошибок (try/except)

## Что такое ошибка в программе

Иногда программа во время работы натыкается на что-то, с чем не может
справиться: например, просит превратить в число слово "привет" или
пытается поделить на ноль. Тогда Python останавливается и показывает
красную ошибку — программа "падает" (крашится).

```python
число = int("привет")   # Python не может превратить "привет" в число
```

Если запустить такой код, программа остановится с ошибкой
`ValueError` и ничего дальше не выполнится.

## try/except — "страховка" для кода

Чтобы программа не падала, а могла аккуратно среагировать на проблему,
используют конструкцию **try/except**. Это как страховочная сетка под
канатоходцем: если что-то пошло не так, сетка ловит и не даёт упасть.

```python
try:
    число = int("привет")   # пробуем выполнить рискованный код
    print("Число:", число)
except ValueError:
    print("Ой! Это не похоже на число.")
```

Python сначала пытается выполнить код внутри `try`. Если всё хорошо —
код `except` вообще не выполняется. Если же в `try` случилась ошибка —
Python сразу переходит к `except` и выполняет его, а программа
продолжает работать дальше, а не падает.

## ZeroDivisionError — деление на ноль

Ещё одна частая ошибка — деление числа на ноль. Математика не разрешает
так делать, и Python выдаёт ошибку `ZeroDivisionError`.

```python
try:
    результат = 10 / 0
    print(результат)
except ZeroDivisionError:
    print("На ноль делить нельзя!")
```

## Запомни

- Ошибка во время работы программы называется **исключением**.
- `try:` — блок кода, который мы "пробуем" выполнить.
- `except ОшибкаТакаяТо:` — что делать, если в `try` случилась именно
  такая ошибка.
- `ValueError` — ошибка при неправильном превращении текста в число.
- `ZeroDivisionError` — ошибка при делении на ноль.
- try/except не даёт программе упасть — она продолжает работать дальше.
