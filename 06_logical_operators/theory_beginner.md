# Тема 6: логические операторы and, or, not

## Когда нужно проверить сразу два условия

Иногда одного условия недостаточно. Например: "можно пойти гулять, ЕСЛИ
уроки сделаны И на улице не дождь". Здесь сразу два условия, и оба
должны быть верными. Для этого в Python есть слово **`and`** ("и").

```python
uroki_sdelany = True
net_dozhdya = True

if uroki_sdelany and net_dozhdya:
    print("Можно идти гулять!")
else:
    print("Пока нельзя гулять")
```

`and` — это как строгий учитель: пропустит, только если **все**
условия верны. Если хотя бы одно условие False — весь результат False.

## Когда достаточно хотя бы одного условия

А бывает наоборот: "можно посмотреть мультик, ЕСЛИ сегодня выходной ИЛИ
уроки уже сделаны". Тут достаточно, чтобы верным было хотя бы одно
условие. Для этого есть слово **`or`** ("или").

```python
vyhodnoy = False
uroki_sdelany = True

if vyhodnoy or uroki_sdelany:
    print("Можно посмотреть мультик")
else:
    print("Сначала сделай уроки")
```

`or` — это добрый учитель: пропустит, если хотя бы одно условие верно.

## Как перевернуть условие наоборот

Иногда нужно проверить, что что-то НЕ выполняется. Для этого есть
слово **`not`** ("не"). Оно переворачивает `True` в `False` и наоборот.

```python
idet_dozhd = False

if not idet_dozhd:
    print("Дождя нет, можно гулять без зонта")
```

## Таблица для запоминания

- `and` — True, только если ОБА условия True.
- `or` — True, если ХОТЯ БЫ ОДНО условие True.
- `not` — переворачивает True в False, а False в True.

```python
print(True and False)   # False
print(True or False)    # True
print(not True)         # False
```

## Можно комбинировать несколько условий

```python
vozrast = 13
est_razreshenie = True

if vozrast >= 12 and est_razreshenie:
    print("Можно смотреть фильм")
```

## Запомни

- `and` ("и") — верно, только если верны все условия.
- `or` ("или") — верно, если верно хотя бы одно условие.
- `not` ("не") — переворачивает True в False и наоборот.
- Логические операторы можно комбинировать вместе с `if`/`elif`/`else`.
- Для группировки условий удобно использовать скобки: `(a and b) or c`.
