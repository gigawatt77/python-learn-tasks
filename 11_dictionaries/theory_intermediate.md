# Тема 11: Словари

Словарь (`dict`) хранит данные как пары "ключ -> значение". В отличие от
списка, элементы словаря не имеют порядкового индекса — доступ идёт по
ключу, что делает поиск быстрым даже для больших наборов данных.

```python
player = {"name": "Макс", "level": 7, "hp": 100}
```

Ключами могут быть строки, числа и другие неизменяемые типы; значениями —
что угодно, включая списки и другие словари.

## Доступ, изменение, удаление

```python
player = {"name": "Макс", "level": 7}

print(player["name"])          # доступ по ключу, KeyError если ключа нет
print(player.get("hp", 0))     # безопасный доступ, 0 - значение по умолчанию

player["level"] = 8            # обновление значения
player["hp"] = 100             # добавление нового ключа
del player["hp"]               # удаление ключа

print("level" in player)       # проверка наличия ключа -> True/False
```

## Перебор

```python
scores = {"Аня": 91, "Максим": 78, "Соня": 85}

for name in scores:                       # перебор по ключам (по умолчанию)
    print(name)

for name, score in scores.items():        # перебор пар ключ-значение
    print(name, score)

for score in scores.values():             # перебор только значений
    print(score)
```

## Пример: словарь как счётчик

Словари часто используют для подсчёта чего-либо:

```python
words = ["кот", "пёс", "кот", "кот", "пёс"]
count = {}

for word in words:
    if word in count:
        count[word] = count[word] + 1
    else:
        count[word] = 1

print(count)   # {'кот': 3, 'пёс': 2}
```

## Запомни

- `d = {"ключ": значение}` — создание словаря.
- `d["ключ"]` — доступ (ошибка, если ключа нет); `d.get("ключ", default)`
  — безопасный доступ.
- `d["ключ"] = значение` — добавить или обновить.
- `del d["ключ"]` — удалить ключ.
- `"ключ" in d` — проверка наличия ключа.
- `d.items()`, `d.keys()`, `d.values()` — способы перебора словаря.
