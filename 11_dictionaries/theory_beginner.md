# Тема 11: Словари

## Что такое словарь

Представь телефонную книгу: там нет номеров ящиков по порядку, зато
есть имя человека и рядом с ним — номер телефона. Чтобы найти номер, не
нужно перебирать всю книгу — достаточно знать имя. В Python такая
структура называется **словарь** (`dict`).

Словарь хранит пары "**ключ** -> **значение**". Ключ — это как имя в
телефонной книге, а значение — то, что с ним связано.

```python
phonebook = {"Миша": "111-22-33", "Максим": "444-55-66"}
print(phonebook)
```

## Доступ по ключу

Чтобы получить значение, нужно написать имя словаря и в квадратных
скобках — ключ (а не номер по порядку, как в списке!):

```python
phonebook = {"Миша": "111-22-33", "Максим": "444-55-66"}
print(phonebook["Миша"])   # 111-22-33
```

Если такого ключа нет, Python выдаст ошибку `KeyError`. Чтобы избежать
ошибки, можно использовать метод `get()` — он вернёт `None` (пустоту),
если ключа нет, вместо того чтобы "падать":

```python
print(phonebook.get("Соня"))   # None (такого ключа нет)
```

## Добавление и удаление ключей

Словарь можно менять после создания:

```python
student = {"имя": "Миша", "возраст": 12}

student["класс"] = "6А"       # добавили новый ключ "класс"
print(student)

del student["возраст"]        # удалили ключ "возраст"
print(student)
```

Если записать значение по уже существующему ключу — старое значение
заменится новым:

```python
student["возраст"] = 13   # обновили возраст
```

## Перебор словаря

Чтобы пройтись по всем парам ключ-значение, используют цикл `for` вместе
с методом `.items()`:

```python
student = {"имя": "Миша", "возраст": 12, "класс": "6А"}

for key, value in student.items():
    print(key, "-", value)
```

Результат:

```
имя - Миша
возраст - 12
класс - 6А
```

Есть также `.keys()` — только ключи, и `.values()` — только значения.

## Запомни

- Словарь: `d = {"ключ": значение, "ключ2": значение2}`.
- Доступ по ключу: `d["ключ"]` (ошибка, если ключа нет).
- `d.get("ключ")` — безопасный доступ, вернёт `None`, если ключа нет.
- Добавить/изменить: `d["новый_ключ"] = значение`.
- Удалить: `del d["ключ"]`.
- Перебор: `for key, value in d.items():`.
- `d.keys()` — все ключи, `d.values()` — все значения.
