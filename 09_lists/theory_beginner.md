# Тема 9: Списки

## Что такое список

Представь ряд пронумерованных ящиков или рюкзак, в который можно
складывать вещи одну за другой. В Python такой "ряд ящиков" называется
**список** (`list`). В нём можно хранить сразу много значений: имена
друзей, оценки, названия игр — что угодно.

Список создаётся с помощью квадратных скобок `[]`, а значения внутри
разделяются запятыми:

```python
fruits = ["яблоко", "банан", "груша"]
print(fruits)
```

На экране появится:

```
['яблоко', 'банан', 'груша']
```

## Индексы — номера ящиков

Каждый ящик в списке имеет свой номер — **индекс**. Важно запомнить:
**нумерация начинается с нуля!** Первый элемент — это индекс `0`,
второй — `1`, и так далее.

```python
fruits = ["яблоко", "банан", "груша"]
print(fruits[0])   # яблоко
print(fruits[1])   # банан
print(fruits[2])   # груша
```

Если попросить элемент с индексом, которого нет (например, `fruits[10]`),
Python выдаст ошибку `IndexError`.

Есть и удобный трюк — отрицательные индексы. `fruits[-1]` — это
**последний** элемент, `fruits[-2]` — предпоследний.

## Срезы — берём кусочек списка

Срез (`slice`) позволяет достать сразу несколько элементов подряд —
как отрезать кусок ленты. Пишется так: `список[начало:конец]`. Элемент
с индексом "конец" в срез **не входит**.

```python
numbers = [10, 20, 30, 40, 50]
print(numbers[1:3])   # [20, 30]
print(numbers[:2])    # [10, 20]  — от начала до индекса 2
print(numbers[3:])    # [40, 50]  — от индекса 3 до конца
```

## Добавляем и убираем элементы

Список можно менять после создания:

```python
backpack = ["тетрадь", "ручка"]
backpack.append("линейка")     # добавили в конец
print(backpack)                # ['тетрадь', 'ручка', 'линейка']

backpack.remove("ручка")       # убрали ручку
print(backpack)                # ['тетрадь', 'линейка']
```

- `append(значение)` — кладёт новый элемент в конец списка.
- `remove(значение)` — убирает первый найденный элемент с таким значением.

Ещё полезно знать `len(список)` — сколько всего элементов в списке.

## Перебор списка циклом for

Часто нужно "пройтись" по каждому элементу списка — например, напечатать
все имена по очереди. Для этого используют цикл `for`:

```python
fruits = ["яблоко", "банан", "груша"]
for fruit in fruits:
    print(fruit)
```

Это работает так: на каждом шаге переменная `fruit` по очереди
становится равна каждому элементу списка, и тело цикла выполняется для
неё. Программа сама остановится, когда элементы закончатся.

## Запомни

- Список создаётся так: `mylist = [1, 2, 3]`.
- Индексы начинаются с **нуля**: `mylist[0]` — первый элемент.
- Срез `mylist[a:b]` берёт элементы с индекса `a` до `b` (не включая `b`).
- `mylist.append(x)` — добавить элемент в конец.
- `mylist.remove(x)` — удалить первый элемент со значением `x`.
- `len(mylist)` — узнать количество элементов.
- `for item in mylist:` — перебрать все элементы списка по очереди.
