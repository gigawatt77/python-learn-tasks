# Учимся программировать на Python 🐍

Привет! Это твой личный задачник по Python. Он поможет тебе шаг за шагом
научиться писать настоящие программы — от простого `print("Привет!")`
до собственной текстовой игры.

## Как этим пользоваться

1. Установи [VS Code](https://code.visualstudio.com/) и расширение **Python**
   (в VS Code слева есть значок квадратиков — Extensions — найди там "Python"
   от Microsoft и нажми Install).
2. Открой папку `python-learn-tasks` в VS Code (`File → Open Folder...`).
3. Темы идут по порядку — от `01_...` до `16_...`. Не перепрыгивай вперёд,
   каждая тема опирается на предыдущие.
4. В каждой теме:
   - Сначала прочитай теорию: `theory_beginner.md` (если ты вообще
     первый раз видишь код) или `theory_intermediate.md` (если ты уже
     пробовал Scratch или блочное программирование).
   - Посмотри `example.py` — это уже решённая задача с объяснениями.
   - Реши задачи в папке `tasks/` — открывай файл `task_01.py`, пиши код
     вместо `TODO`, и запускай.
   - Если застрял — подглядывай в `solutions/`, но старайся сначала
     решить сам!

## Как запустить программу в VS Code

1. Открой файл (например, `tasks/task_01.py`).
2. Нажми на зелёный треугольник ▷ в правом верхнем углу окна
   ("Run Python File"). Либо нажми правой кнопкой мыши по коду →
   **Run Python File in Terminal**.
3. Результат появится внизу, в панели **Terminal**.
4. Если видишь красный текст с ошибкой (`Error`) — не пугайся! Прочитай
   последнюю строчку, там обычно написано, что не так. Ошибки — это
   нормальная часть программирования, их допускают даже профессионалы.
