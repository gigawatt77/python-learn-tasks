# Тема 12: Функции

Функция — именованный блок кода, который можно вызывать многократно.
Определяется через `def`, тело функции выделяется отступом (как у `if`
и `for`).

```python
def greet(name):
    print(f"Привет, {name}!")

greet("Миша")
```

## Параметры и аргументы

Параметры — переменные в определении функции; аргументы — значения,
которые передаются при вызове. Параметров может быть несколько:

```python
def add(a, b):
    return a + b

result = add(3, 5)   # a=3, b=5
print(result)         # 8
```

## return vs print

`print()` только показывает значение на экране, а `return` передаёт
результат обратно туда, откуда функция была вызвана — его можно
сохранить в переменную и использовать дальше в коде. Функция без
`return` возвращает `None`.

```python
def double(x):
    return x * 2

value = double(10)      # value = 20, можно использовать дальше
print(value + 1)        # 21
```

## Параметры по умолчанию

```python
def power(base, exponent=2):
    return base ** exponent

print(power(3))       # 9  (exponent взял значение по умолчанию 2)
print(power(3, 3))    # 27 (exponent явно указан)
```

Параметры со значением по умолчанию должны идти **после** обычных
параметров.

## Несколько параметров, разные типы аргументов

```python
def describe(name, age, city="неизвестно"):
    print(f"{name}, {age} лет, город: {city}")

describe("Соня", 12)                    # позиционные аргументы
describe("Макс", 13, city="Москва")     # именованный аргумент
```

## Запомни

- `def f(a, b=default):` — определение функции с обычными параметрами
  и параметрами по умолчанию (они идут последними).
- Вызов функции: `f(значение1, значение2)`.
- `return` возвращает результат вызывающему коду; без `return` функция
  возвращает `None`.
- `print()` внутри функции только выводит текст, но не передаёт значение
  дальше в программу.
