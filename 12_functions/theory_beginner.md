# Тема 12: Функции

## Что такое функция

Представь рецепт торта. Ты не придумываешь заново, как испечь торт,
каждый раз — ты просто следуешь рецепту. И если ты хочешь испечь торт
ещё раз, ты снова берёшь тот же рецепт. В программировании такой
"рецепт" называется **функция** — кусок кода, который можно написать
один раз и использовать много раз.

Мы уже пользовались готовыми функциями: `print()`, `len()`. Теперь
научимся создавать свои!

## Создание функции: def

Функция создаётся с помощью слова `def` (сокращение от "define" —
"определить"):

```python
def greet():
    print("Привет!")
    print("Как дела?")
```

Это просто "написали рецепт" — сам код внутри функции пока не
выполнился. Чтобы выполнить его, функцию нужно **вызвать** — написать
её имя со скобками:

```python
greet()   # вот теперь код внутри функции выполнится
greet()   # и ещё раз - можно вызывать сколько угодно раз!
```

## Параметры — данные для функции

Часто функции нужны какие-то данные, чтобы работать. Их передают в
скобках при определении функции — это называется **параметры**:

```python
def greet(name):
    print("Привет,", name, "!")

greet("Миша")      # Привет, Миша !
greet("Максим")   # Привет, Максим !
```

Параметр `name` — как пустой слот в рецепте, куда каждый раз кладут
своё значение.

## return — функция возвращает результат

Функция может не просто печатать что-то, а **возвращать** результат
обратно в программу с помощью `return`. Тогда результат можно сохранить
в переменную и использовать дальше:

```python
def square(number):
    return number * number

result = square(5)
print(result)   # 25
```

## Значения по умолчанию

Параметру можно задать значение "по умолчанию" — тогда его можно не
передавать при вызове, и будет использовано значение по умолчанию:

```python
def greet(name="друг"):
    print("Привет,", name, "!")

greet("Соня")   # Привет, Соня !
greet()         # Привет, друг !  (использовалось значение по умолчанию)
```

## Запомни

- `def имя_функции(параметры):` — создание функции.
- Код внутри функции выполняется только при **вызове**: `имя_функции()`.
- Параметры — это значения, которые функция получает при вызове.
- `return значение` — функция возвращает результат, который можно
  сохранить в переменную.
- `def f(x=значение):` — параметр со значением по умолчанию, его можно
  не указывать при вызове.
