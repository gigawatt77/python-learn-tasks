# Тема 8: цикл for и range()

В Scratch есть блок "повторить N раз" — это прямой аналог `for i in
range(N)`. В отличие от `while`, цикл `for` не требует вручную заводить
и изменять счётчик — он сам перебирает элементы итерируемого объекта
(последовательности).

```python
for i in range(5):
    print(i)   # 0 1 2 3 4
```

## range() подробнее

`range()` — это не список, а специальный "ленивый" объект, который
генерирует числа по требованию (экономит память для больших диапазонов).

```python
range(5)          # 0, 1, 2, 3, 4
range(2, 6)       # 2, 3, 4, 5
range(0, 10, 2)   # 0, 2, 4, 6, 8
range(10, 0, -1)  # 10, 9, 8, ..., 1 (отрицательный шаг — считаем назад)
```

Если нужно получить список чисел явно: `list(range(5))` → `[0, 1, 2, 3, 4]`.

## for по коллекциям

`for` работает с любым итерируемым объектом: строкой, списком,
кортежем и т.д.

```python
imya = "Аня"
for bukva in imya:
    print(bukva)

frukty = ["яблоко", "банан", "груша"]
for frukt in frukty:
    print(frukt)
```

## enumerate() — если нужен и индекс, и значение

```python
frukty = ["яблоко", "банан", "груша"]
for indeks, frukt in enumerate(frukty):
    print(indeks, frukt)
```

## break, continue и else у цикла

`break` и `continue` работают в `for` так же, как в `while`. У цикла
`for` (и `while`) есть редко используемая конструкция `else`, которая
выполняется, только если цикл завершился без `break`:

```python
for i in range(5):
    if i == 10:
        break
else:
    print("Цикл закончился без break")
```

## Запомни

- `for переменная in range(...):` перебирает числа без ручного
  управления счётчиком.
- `range(старт, конец, шаг)` — гибкая генерация чисел, конец не
  включается.
- `for` работает с любой последовательностью: строкой, списком и т.д.
- `enumerate()` даёт одновременно индекс и значение элемента.
- `break`/`continue` работают в `for` точно так же, как в `while`.
