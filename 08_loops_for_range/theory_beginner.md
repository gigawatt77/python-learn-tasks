# Тема 8: цикл for и range()

## Ещё один способ повторять действия

В прошлой теме мы учились повторять код с помощью `while`, но каждый
раз приходилось вручную заводить счётчик и не забывать его менять.
Если заранее известно, сколько раз нужно повторить действие, удобнее
использовать цикл **`for`** ("для каждого").

```python
for i in range(5):
    print("Привет!")
```

Этот код напечатает "Привет!" ровно 5 раз. Разберём:
- `for i in ...:` — "для каждого значения i из..."
- `range(5)` — специальная команда, которая создаёт последовательность
  чисел от 0 до 4 (всего 5 чисел, но не включая само число 5!).
- `i` — переменная-счётчик, она сама меняется на каждом шаге цикла, её
  не нужно увеличивать вручную, как в `while`.

Если напечатать саму переменную `i`, будет видно, как она меняется:

```python
for i in range(5):
    print(i)
```

Вывод:
```
0
1
2
3
4
```

## range() с двумя и тремя числами

`range()` умеет работать не только "от 0 до...", но и с началом,
концом и шагом:

```python
for i in range(2, 6):        # от 2 до 5 (6 не включается)
    print(i)

for i in range(0, 10, 2):    # от 0 до 9 с шагом 2 (только чётные)
    print(i)
```

## for по списку или строке

`for` умеет проходить не только по числам из `range()`, но и по
элементам списка или буквам строки:

```python
frukty = ["яблоко", "банан", "груша"]

for frukt in frukty:
    print(frukt)
```

## break и continue работают и в for

Так же, как и в `while`, в цикле `for` можно использовать `break`
(выйти из цикла) и `continue` (пропустить шаг):

```python
for i in range(10):
    if i == 5:
        break
    print(i)
```

## Запомни

- `for переменная in range(n):` — повторяет код n раз (переменная
  принимает значения от 0 до n-1).
- `range(старт, конец)` — числа от старта до конца-1.
- `range(старт, конец, шаг)` — то же самое, но с указанным шагом.
- `for` может проходить по элементам списка или символам строки.
- `break` и `continue` работают в `for` так же, как и в `while`.
